# reservasHotel
Tercer punto,  taller 4

Un hotel administra sus habitaciones y las reservas realizadas por sus huéspedes. Cada habitación tiene un número, un tipo y un estado que puede ser disponible, ocupada o en mantenimiento. Solo el administrador puede cambiar el estado de una habitación. Un huésped puede consultar las habitaciones disponibles y realizar una reserva. Cada reserva relaciona un huésped con una habitación y registra las fechas de entrada y salida. Si se elimina una reserva, la habitación y el huésped deben permanecer en el sistema.
